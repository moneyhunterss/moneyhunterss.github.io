LeadFinder — anonymous gig scanner

Personal project · 2026 · Python, SQLite, Telegram API
Problem
Freelancer needed to find paid gigs across 50+ Reddit subs without manually checking each one daily.
Approach
Built a Python scanner that hits Reddit RSS + HN Algolia + Bitcointalk + 4chan + RSS feeds, applies strict regex + LLM scoring, pings Telegram with new leads + reply text in code blocks.

25-40 leads/scan, every 15 min, fully autonomous on GitHub Actions free tier. Includes 18-command bot for pipeline tracking + earnings stats.
