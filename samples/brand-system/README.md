# Brand Identity System

Three brand identity concepts for fictional startups. Each set includes:
- Primary logo (SVG, scalable)
- Color palette
- Typography system
- Usage guidelines

## 1. Meridian Studio (creative agency)

**Logo:** Gradient orange-to-red square with monogram "M"
**Palette:**
- Primary: `#f59e0b` (amber)
- Accent: `#dc2626` (red)
- Dark: `#0a0a0f`
- Muted: `#71717a`

**Typography:**
- Display: Inter 800
- Body: Inter 400
- Caption: Inter 500, letter-spacing 2px

## 2. Verdant Capital (fintech)

**Logo:** Concentric circles in emerald green
**Palette:**
- Primary: `#10b981` (emerald)
- Dark: `#0a0a0f`
- Muted: `#71717a`

**Typography:**
- Display: Inter 700
- Body: Inter 400

## 3. Apex Labs (dev tools)

**Logo:** Stylized "A" with apex peak, purple + amber accent
**Palette:**
- Primary: `#8b5cf6` (violet)
- Accent: `#f59e0b` (amber)

## Process

1. **Discovery** — client fills out 1-page brief (5 min)
2. **Concepts** — 3 directions delivered in 48h
3. **Iteration** — 2 rounds of revisions on chosen direction
4. **Delivery** — SVG source + color codes + typography scale + 24-pg brand guide PDF
